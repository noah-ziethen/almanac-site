Privacy policy

Almanac · last updated 7 November 2026

Almanac is a personal calendar and shopping list app that runs on its user's own reMarkable tablet. It has no server of its own, and the developer receives no user data.

Google data it accesses

  • Calendar events, read, created and deleted on the user's calendars.
  • The list of calendars, read only.
  • Google Tasks. Almanac's permission covers all of the user's tasks, because Google offers no narrower one for making changes. Almanac reads task list names to find a list called "Shopping", creating it if missing, and only reads and changes tasks in that list.

How the data is used and stored

This data is used only to show and change the calendar and shopping list on the tablet. Events, shopping items, unsent changes and the Google sign-in token are stored in files on the tablet. Data is sent only to Google, over encrypted connections, except for the weather described below.

Weather

If the user sets a place for the weather, Almanac sends its coordinates to Open-Meteo to get a forecast. No Google data is sent with them. Open-Meteo's own terms and privacy policy apply to that request.

Handwriting

When the user handwrites text and taps Convert, the pen strokes are sent to Google's handwriting recognition service (Google Input Tools) to be turned into text. Almanac does not keep them after the text is inserted. Google's own privacy policy applies to data sent to Google.

Sharing

Almanac does not sell this data, share it with third parties other than Google as described above, use it for advertising, or use it to train AI models.

Removing access and data

Access can be removed at any time at myaccount.google.com/permissions. Deleting Almanac's folder from the tablet removes its stored data.

Contact

Questions can be raised through this project's GitHub issues.
